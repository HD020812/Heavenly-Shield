# 🛰️ Nebesniy_Shit: Anti-Air Tactical Simulator

**Nebesniy_Shit** — це хардкорний тактичний симулятор протиповітряної оборони (ППО), розроблений на Python з використанням бібліотеки Pygame. Гравець виступає в ролі оператора оборонного комплексу, який динамічно розподіляє ресурси для захисту повітряного простору від масованих нальотів ворожих БПЛА.

---

## 🎯 Основні Особливості

*   **Реалістичні візуальні асети:** Моделі баражуючих боєприпасів (камікадзе "Shahed") відтворені на основі реальних фотознімків та креслень, що забезпечує глибоку атмосферу та впізнаваний силует загроз.
*   **Динамічний менеджмент ресурсів:** Гра вимагає від гравця миттєвої оцінки ситуації, контролю перегріву орудій та бережливого розходу боєкомплекту.
*   **Система хвильового спавну:** Наростаюча складність та адаптивні траєкторії польоту цілей тестують швидкість реакції та стратегічне мислення.

---

## 🛡️ Доступне Озброєння (Режими ППО)

Симулятор включає в себе 4 унікальних калібри оборонних систем, кожен зі своєю бальністикою, скорострільністю та призначенням:

1.  **💥 Великокаліберний кулемет Browning (12.7 мм)** — високий темп стрільби, ідеальний для знищення низьколітаючих дронів на ближній дистанції. Вимагає контролю перегріву.
2.  **🐊 ЗСУ Gepard** — спарені автоматичні гармати, які випускають щільний потік снарядів по ламаній траєкторії для ефективного зрізання хвиль БПЛА.
3.  **🚀 ПЗРК Stinger** — ракетний комплекс ближньої дії. Працює за принципом "вистрілив і забув", наводячись по тепловому сліду скоросних цілей. Обмежений боєзапас.
4.  **🛡️ ЗРК Patriot** — важка далекобійна артилерія. Ультимативний щит для перехоплення балістичних траєкторій та найнебезпечніших загроз на величезній висоті.
